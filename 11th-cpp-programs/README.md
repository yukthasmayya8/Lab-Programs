# 11th Grade C++ Lab Programs

A curated collection of foundational C++ programs developed during 11th grade Computer Science. These programs cover essential programming concepts including control structures, arrays, strings, matrices, functions, and structures.

---

## About

This repository contains classic beginner-level C++ exercises commonly taught in Class 11 curricula. Each program focuses on a specific concept and is implemented using standard C++ features with simple, easy-to-understand logic.

---

## Programs

| File | Description |
|------|-------------|
| `area_circumference_of_circle.cpp` | Calculates the area and circumference of a circle |
| `area_of_triangle.cpp` | Calculates the area of a triangle |
| `armstrong_number.cpp` | Checks whether a given number is an Armstrong number |
| `arrange_ascending_order(arrays).cpp` | Sorts an array of numbers in ascending order |
| `calculate_net_amount_discount.cpp` | Calculates the net amount after applying a discount |
| `check_palindrome.cpp` | Checks if a given string is a palindrome |
| `check_scalar_matrix.cpp` | Determines whether a matrix is a scalar matrix |
| `compound_interest.cpp` | Computes compound interest |
| `convert_days_to_years_months_days.cpp` | Converts a total number of days into years, months, and days |
| `count_of_vowels_consonants(strings).cpp` | Counts the number of vowels and consonants in a string |
| `factorial.cpp` | Calculates the factorial of a number |
| `fibonacci_series.cpp` | Generates the Fibonacci series up to *n* terms |
| `largest_second_largest_smallest.cpp` | Finds the largest, second largest, and smallest among three numbers |
| `lcm_gcd_of_numbers(functions).cpp` | Finds the LCM and GCD of two numbers using functions |
| `leap_year.cpp` | Checks whether a given year is a leap year |
| `position_of_element(arrays).cpp` | Finds the position of a specific element in an array |
| `second_largest(arrays).cpp` | Finds the second largest element in an array |
| `student_information(structures).cpp` | Stores and displays student information using structures |
| `sum_average_of_n_numbers(arrays).cpp` | Calculates the sum and average of *n* numbers using arrays |
| `sum_of_digits_of_number.cpp` | Calculates the sum of digits of a number |
| `sum_of_rows_columns(matrix).cpp` | Calculates the sum of each row and column of a matrix |
| `sum_two_matrices.cpp` | Adds two compatible matrices |
| `swap_values_with_temporary_variables.cpp` | Swaps two values using a temporary variable |
| `swap_values_without_temporary_variables.cpp` | Swaps two values without using a temporary variable |
| `uppercase_lowercase_character.cpp` | Converts a character between uppercase and lowercase |
| `x^y_number(functions).cpp` | Calculates \(x^y\) using a user-defined function |

## Getting Started

### Prerequisites

- A C++ compiler (g++, clang++, or MSVC)

### Compilation & Execution

```bash
# Compile
g++ filename.cpp -o filename

# Run
./filename
```
