# Engineering 1st Year Python Programs

A collection of Python lab programs of my first year of engineering. These cover core concepts such as lists, file handling, exception handling, recursion, OOP, sorting, and basic data analysis.

---

## About

These are the Python lab programs and exercises I completed in first year. Each program focuses on a specific concept and uses standard Python with console-based input/output.

---

## Programs

| File | Description |
|------|-------------|
| `addition_of_complex_numbers(oops).py` | Adds two complex numbers using object-oriented programming |
| `bubble_sort_marks.py` | Sorts student marks using bubble sort |
| `calculator.py` | Simple calculator performing basic arithmetic operations |
| `data_summary_generator.py` | Generates a summary from COVID-related CSV data |
| `display_contents_of_folder(recursion).py` | Displays folder contents using recursion |
| `divide_numbers_with_exception_handling.py` | Divides two numbers with exception handling |
| `fibonacci_series.py` | Generates the Fibonacci series |
| `frequency_of_digit.py` | Finds the frequency of a digit in a number |
| `list_operations.py` | Performs various operations on lists |
| `mean_variance_standard_deviation.py` | Calculates mean, variance, and standard deviation |
| `most_frequent_words.py` | Finds the most frequent words in a text file |
| `senior_citizen.py` | Checks eligibility for senior citizen benefits |
| `sort_items_in_text_file.py` | Sorts items stored in a text file |
| `student_grade_tracker.py` | Tracks and calculates student grades |
| `text_analysis_tool.py` | Performs basic text analysis |
