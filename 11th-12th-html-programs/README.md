# 11th–12th Grade HTML Programs

A collection of HTML programs of my 11th and 12th grade. These cover foundational web development concepts such as basic page structure, text formatting, lists, tables, forms, hyperlinks, and image embedding.

---

## About

These are the HTML lab programs and exercises I completed in high school. Each program focuses on a specific concept and uses plain HTML with simple browser-based rendering (no CSS or JavaScript).

---

## Programs

| File | Description |
|------|-------------|
| `college_website.html` | Simple college information page with formatted text, background color, and a hyperlink to the courses page |
| `courses.html` | Displays the courses and language options offered by the college using ordered and unordered lists, plus an embedded image |
| `student_application_form.html` | Student application form using a table layout with text inputs, radio buttons, dropdown, and submit/cancel buttons |
| `study_time_table.html` | Personal study timetable displayed in a structured HTML table with a scrolling marquee message |

## Getting Started

### Prerequisites
- Any modern web browser (Chrome, Firefox, Edge, etc.)

### Running a Program

Simply open any `.html` file in your browser:

```bash
# Example (Windows)
start college_website.html

# Example (macOS)
open college_website.html

# Example (Linux)
xdg-open college_website.html
