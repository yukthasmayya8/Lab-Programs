# 12th Grade C++ Lab Programs

A curated collection of intermediate C++ programs developed during 12th grade Computer Science. These programs cover advanced programming concepts including object-oriented programming, data structures, arrays, functions, and constructors.

---

## About

This repository contains classic intermediate-level C++ exercises commonly taught in Class 12 curricula. Each program focuses on a specific concept and is implemented using standard C++ features with simple console-based input/output.

---

## Programs

| File | Description |
|------|-------------|
| `appending_nodes_to_linked_list.cpp` | Demonstrates appending nodes to a singly linked list |
| `area_square_rectangle_triangle(function_overloading).cpp` | Calculates area of square, rectangle, and triangle using function overloading |
| `binary_search(arrays).cpp` | Implements binary search on a sorted array |
| `cube_of_number(inline_function).cpp` | Computes the cube of a number using an inline function |
| `delete_item_from_position(arrays).cpp` | Deletes an element from a specified position in an array |
| `enqueue_dequeue.cpp` | Implements enqueue and dequeue operations on a queue |
| `frequency_of_elements(arrays).cpp` | Finds the frequency of each element in an array |
| `insert_element_at_position(arrays).cpp` | Inserts an element at a specified position in an array |
| `pop_elements(stack).cpp` | Demonstrates the pop operation on a stack |
| `push_items(stack).cpp` | Demonstrates the push operation on a stack |
| `quadratic_roots.cpp` | Finds the roots of a quadratic equation |
| `read_display(pointers_to_objects).cpp` | Reads and displays object data using pointers to objects |
| `simple_interest.cpp` | Calculates simple interest |
| `sort_elements_insertionsort(arrays).cpp` | Sorts an array using the insertion sort algorithm |
| `student_information(inheritance).cpp` | Manages student information using inheritance |
| `sum_of_series(constructor).cpp` | Calculates the sum of a series using a constructor |
