# Engineering 1st Year C Lab Programs

A curated collection of foundational C programs developed during the first year of engineering. These programs cover essential programming concepts including arrays, structures, functions, sorting & searching techniques, strings, and mathematical computations.

---

## About

This repository contains classic first-year engineering C laboratory exercises. Each program focuses on a specific concept and is implemented using standard C features with simple console-based input/output.

---

## Programs

| File | Description |
|------|-------------|
| `binary_search.c` | Implements binary search on a sorted array |
| `book_details_structure.c` | Stores and displays book details using structures |
| `bubble_sort_descending.c` | Sorts an array in descending order using bubble sort |
| `call_by_value_reference.c` | Demonstrates call by value and call by reference |
| `check_student_result.c` | Checks and displays a student's result based on marks |
| `distance_between_points.c` | Calculates the distance between two points |
| `kyc_verification.c` | Simulates a basic KYC verification process |
| `quadratic_roots.c` | Finds the roots of a quadratic equation |
| `search_keyword.c` | Searches for a keyword in a given text |
| `sine_series.c` | Computes the sine of a number using Taylor series |
| `string_concatenation_length.c` | Concatenates two strings and finds their lengths |
| `student_grade.c` | Calculates and displays a student's grade |
| `swap_balances.c` | Swaps the balances of two accounts |
| `total_branch_revenue.c` | Calculates the total revenue of different branches |
